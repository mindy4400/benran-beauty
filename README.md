# 本然美苑 GitHub Pages 網站

## 發布方式

1. 在 GitHub 建立新的 Public repository，例如 `benran-beauty`。
2. 將本資料夾內所有檔案上傳到 repository 根目錄。
3. 開啟 `Settings` → `Pages`。
4. 在 `Build and deployment` 的 Source 選擇 `Deploy from a branch`。
5. Branch 選擇 `main`，Folder 選擇 `/(root)`，然後按 `Save`。
6. 等候部署完成，GitHub 會顯示公開網址。

## 修改內容

- 網站文字：編輯 `index.html`
- 顏色與排版：編輯 `style.css`
- 圖片：替換 `assets/images` 內同名檔案
- LINE 網址：搜尋 `https://lin.ee/O4V5L1I` 後全部替換

## 注意事項

- `assets/images/hero-scalp-care.png`、`plant-care.png`、`home-service.png` 必須保留檔名，網站才會正常顯示。
- 網站沒有公開電話與價格，所有預約均導向官方 LINE。
